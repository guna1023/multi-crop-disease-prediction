# 🌿 AI-Based Multi-Crop Disease Detection Using Deep Learning

A final-year project that detects **Tomato** and **Corn (Maize)** leaf
diseases from images using **MobileNetV2 transfer learning**, served
through a local/hosted **Streamlit** web app.

🔗 **Live Demo:** https://multi-crop-disease-prediction-8nxslfqvft5ujqvskprx3h.streamlit.app/

## ✨ Features

- Detects diseases across **2 crops**: Tomato and Corn (Maize)
- **MobileNetV2** transfer learning (ImageNet pretrained, fine-tuned)
- Two-stage training: frozen-base head training → fine-tuning
- Automatic class detection from dataset folder names — no hardcoding
- Class-weighted training to handle imbalanced datasets
- Data augmentation & preprocessing baked directly into the model graph
- Full evaluation suite: accuracy, precision, recall, F1-score, confusion matrix
- Simple, interactive **Streamlit** web interface
- Runs 100% locally, and deployable for free on Streamlit Community Cloud

## 🚀 Getting Started (Run Locally)

```bash
# 1. Clone the repo
git clone https://github.com/YOUR_USERNAME/multi-crop-disease-detection.git
cd multi-crop-disease-detection

# 2. Create & activate a virtual environment
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS/Linux

# 3. Install dependencies
pip install -r requirements.txt

# 4. Add your dataset (see "Dataset" section below), then:
python prepare_dataset.py
python train.py
python evaluate.py

# 5. Launch the app
streamlit run app.py
```

---

## 📊 Dataset

- Source: Kaggle PlantVillage-style Tomato and Corn leaf disease datasets.
- Expected folder naming: `Crop___Disease` (e.g. `Tomato___Early_blight`, `Corn_(maize)___Common_rust_`).
- Place all class folders directly inside `dataset_raw/` before running `prepare_dataset.py`.
- Datasets are **not included** in this repo due to size — download them yourself from Kaggle.

## 🌐 Deployment

This app is deployed for free on **Streamlit Community Cloud**.
To deploy your own copy:
1. Push this repo to your GitHub account.
2. Go to [share.streamlit.io](https://share.streamlit.io) → sign in with GitHub.
3. Click **New app** → select your repo, branch `main`, main file `app.py`.
4. Click **Deploy**.
